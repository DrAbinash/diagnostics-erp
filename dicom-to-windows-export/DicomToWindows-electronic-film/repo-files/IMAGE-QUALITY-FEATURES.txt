IMAGE QUALITY ENHANCEMENTS
================================================================================

CLAHE (Contrast Limited Adaptive Histogram Equalization)
---------------------------------------------------------
WHAT IT DOES:
- Enhances local contrast in images
- Particularly effective for medical imaging (X-rays, MRIs)
- Prevents over-amplification of noise (unlike global histogram equalization)
- Makes subtle details more visible

CONFIGURATION:
- ENABLE_CLAHE: true/false (default: true)
- CLAHE_CLIP_LIMIT: 0.1-10.0 (default: 2.0)
  * Lower values = more natural look
  * Higher values = more contrast enhancement
  * Medical images: 2.0-4.0 recommended
- CLAHE_GRID_SIZE: 1-16 (default: 8)
  * Grid size for local histogram calculation
  * Larger = smoother transitions
  * Medical images: 8 recommended
- CLAHE_NORMALIZE: true/false (default: true)
  * Normalize output to full dynamic range

WHEN TO USE:
- X-ray films with low contrast
- Images where details are hard to see
- Medical imaging in general (designed for this)

NOISE REDUCTION (Denoising)
----------------------------
WHAT IT DOES:
- Reduces graininess/noise in images
- Preserves important edges and details
- Uses non-local means algorithm (advanced)
- Makes images cleaner and more professional

CONFIGURATION:
- ENABLE_DENOISE: true/false (default: true)
- DENOISE_STRENGTH: 1-20 (default: 5)
  * Lower values (1-5) = subtle noise reduction
  * Medium values (5-10) = balanced
  * Higher values (10-20) = aggressive (may blur details)
  * Medical images: 3-7 recommended

WHEN TO USE:
- Grainy X-ray films
- Low-dose CT/MRI images
- Any image with visible noise
- Always beneficial for medical imaging

AUTO EXPOSURE CORRECTION
-------------------------
WHAT IT DOES:
- Automatically adjusts brightness and contrast
- Analyzes image histogram
- Stretches dynamic range to use full 0-255
- Fixes under/over-exposed images
- Manual correction factor available

CONFIGURATION:
- ENABLE_AUTO_EXPOSURE: true/false (default: true)
- EXPOSURE_CORRECTION: -1.0 to 1.0 (default: 0.0)
  * 0.0 = no manual adjustment
  * Negative values = darken image
  * Positive values = brighten image
  * Use only if auto correction isn't perfect

WHEN TO USE:
- Images that are too dark or too bright
- Films with poor exposure from X-ray console
- Always beneficial as first processing step

ENHANCEMENT PIPELINE ORDER
---------------------------
The enhancements are applied in this specific order:

1. DENOISE (first)
   - Remove noise before other processing
   - Prevents noise amplification

2. AUTO EXPOSURE (second)
   - Correct overall brightness/contrast
   - Prepare for local enhancement

3. CLAHE (third)
   - Enhance local contrast
   - Bring out fine details

This order is optimized for medical imaging quality.

LAYOUT ADJUSTMENT CONTROLS
================================================================================

PROBLEM SOLVED:
- Image cutting on left side
- Image cutting on bottom
- Images not centered properly
- Margins too tight on one side

MARGIN OFFSETS
--------------
WHAT THEY DO:
- Adjust margins independently for each side
- Compensate for printer alignment issues
- Fix image cutting problems

CONFIGURATION:
- MARGIN_LEFT_OFFSET_MM: -10.0 to 10.0 (default: 0.0)
  * Positive = move image right (increase left margin)
  * Negative = move image left (decrease left margin)
  * Use if image is cut on left side

- MARGIN_RIGHT_OFFSET_MM: -10.0 to 10.0 (default: 0.0)
  * Positive = move image left (increase right margin)
  * Negative = move image right (decrease right margin)
  * Use if image is cut on right side

- MARGIN_TOP_OFFSET_MM: -10.0 to 10.0 (default: 0.0)
  * Positive = move image down (increase top margin)
  * Negative = move image up (decrease top margin)
  * Use if image is cut on top

- MARGIN_BOTTOM_OFFSET_MM: -10.0 to 10.0 (default: 0.0)
  * Positive = move image up (increase bottom margin)
  * Negative = move image down (decrease bottom margin)
  * Use if image is cut on bottom

HOW TO FIX IMAGE CUTTING:
--------------------------
If image is cut on LEFT side:
  → Increase MARGIN_LEFT_OFFSET_MM (try +2.0, +3.0, etc.)

If image is cut on RIGHT side:
  → Increase MARGIN_RIGHT_OFFSET_MM (try +2.0, +3.0, etc.)

If image is cut on TOP:
  → Increase MARGIN_TOP_OFFSET_MM (try +2.0, +3.0, etc.)

If image is cut on BOTTOM:
  → Increase MARGIN_BOTTOM_OFFSET_MM (try +2.0, +3.0, etc.)

IMAGE PADDING
--------------
WHAT IT DOES:
- Adds space around each image within its cell
- Prevents images from touching borders
- Creates professional appearance
- Useful for multi-image layouts

CONFIGURATION:
- IMAGE_PADDING_MM: 0.0 to 20.0 (default: 0.0)
  * 0.0 = no padding (image fills cell)
  * 2.0-5.0 = subtle padding
  * 5.0-10.0 = noticeable padding
  * 10.0+ = large padding

WHEN TO USE:
- Multi-image layouts (2x2, 2x3 grids)
- When images touch each other
- For cleaner, more professional look
- Not needed for single-image films

POSITION OFFSETS
-----------------
WHAT THEY DO:
- Fine-tune image position within cell
- Pixel-level adjustments
- Last resort for alignment issues

CONFIGURATION:
- IMAGE_POSITION_X_OFFSET: -100 to 100 pixels (default: 0)
  * Positive = move right
  * Negative = move left
  * Use for minor horizontal adjustments

- IMAGE_POSITION_Y_OFFSET: -100 to 100 pixels (default: 0)
  * Positive = move down
  * Negative = move up
  * Use for minor vertical adjustments

WHEN TO USE:
- After trying margin offsets
- For very fine alignment
- When margin adjustments aren't precise enough

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Image still cut on left side"
Solution:
- Increase MARGIN_LEFT_OFFSET_MM to 3.0, 4.0, or 5.0
- Check printer margins in Windows printer properties
- Verify PAGE_SIZE matches actual paper size

Problem: "Image too dark after enhancement"
Solution:
- Increase EXPOSURE_CORRECTION to 0.2, 0.3, 0.4
- Or disable ENABLE_AUTO_EXPOSURE and adjust manually
- Check original image brightness

Problem: "Image looks over-processed"
Solution:
- Reduce CLAHE_CLIP_LIMIT to 1.5 or 1.0
- Reduce DENOISE_STRENGTH to 3 or 2
- Disable ENABLE_CLAHE temporarily to isolate issue

Problem: "Enhancements making image worse"
Solution:
- Disable all enhancements: ENABLE_CLAHE=false, ENABLE_DENOISE=false, ENABLE_AUTO_EXPOSURE=false
- Enable one at a time to identify problematic enhancement
- Some images may not benefit from all enhancements

Problem: "Server crashes after enabling enhancements"
Solution:
- Check Python has required libraries: pip install opencv-python numpy Pillow
- Verify image data is valid (not corrupted)
- Check server log for specific error
- Temporarily disable enhancements to confirm stability
