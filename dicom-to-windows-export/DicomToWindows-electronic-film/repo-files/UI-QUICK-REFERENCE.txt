================================================================================
HOW TO USE IMAGE QUALITY CONTROLS
================================================================================

STEP 1: Open Admin UI
----------------------
1. Start server: START-PRINTSCP.bat
2. Open browser: http://localhost:8092
3. Login (default: admin/admin)

STEP 2: Navigate to Calibration Tab
------------------------------------
1. Click "Calibration" in the navigation bar
2. Scroll down to "Advanced Image Quality Enhancements" section

STEP 3: Configure CLAHE (Contrast Enhancement)
-----------------------------------------------
Enable CLAHE: On
  - Recommended for medical images (X-ray, CT, MRI)
  - Enhances local contrast to make details visible

CLAHE Clip Limit: 2.0-4.0
  - Controls enhancement strength
  - Lower (1.0-2.0) = natural look
  - Higher (3.0-4.0) = more contrast
  - Start with 2.5 for X-ray films

CLAHE Grid Size: 8
  - Grid size for local histogram
  - 8 is optimal for medical images
  - Range: 1-16

CLAHE Normalize: Yes
  - Normalizes output to full dynamic range
  - Recommended: Yes

STEP 4: Configure Denoise (Noise Reduction)
--------------------------------------------
Enable Denoise: On
  - Reduces graininess in images
  - Preserves important edges and details

Denoise Strength: 3-7
  - Lower (1-3) = subtle reduction
  - Medium (4-7) = balanced (recommended)
  - Higher (8-20) = aggressive (may blur details)
  - Start with 5 for X-ray films

STEP 5: Configure Auto Exposure
--------------------------------
Enable Auto Exposure: On
  - Automatically corrects brightness/contrast
  - Analyzes histogram and optimizes dynamic range

Exposure Correction: 0.0
  - Manual adjustment if auto isn't perfect
  - Range: -1.0 (darker) to 1.0 (brighter)
  - Start with 0.0 (no manual adjustment)

STEP 6: Save Settings
----------------------
Click: "Save Image Quality Settings"
Settings apply immediately (no restart needed)

RECOMMENDED PRESET FOR X-RAY FILMS:
------------------------------------
Enable CLAHE: On
CLAHE Clip Limit: 2.5
CLAHE Grid Size: 8
CLAHE Normalize: Yes

Enable Denoise: On
Denoise Strength: 5

Enable Auto Exposure: On
Exposure Correction: 0.0

================================================================================
HOW TO USE LAYOUT ADJUSTMENT CONTROLS
================================================================================

PROBLEM: Image cutting on left/bottom sides

STEP 1: Navigate to Film / Layout Tab
--------------------------------------
1. Click "Film / Layout" in navigation bar
2. Scroll to "Layout Adjustment Controls (Fix Image Cutting)" section

STEP 2: Fix Left Side Cutting
------------------------------
If image is cut on LEFT side:
1. Find "Left Margin Offset (mm)"
2. Increase value: try 2.0, 3.0, 4.0
3. Positive values move image RIGHT (away from left edge)
4. Test after each change
5. Stop when cutting is fixed

STEP 3: Fix Right Side Cutting
-------------------------------
If image is cut on RIGHT side:
1. Find "Right Margin Offset (mm)"
2. Increase value: try 2.0, 3.0, 4.0
3. Positive values move image LEFT (away from right edge)

STEP 4: Fix Top Cutting
------------------------
If image is cut on TOP:
1. Find "Top Margin Offset (mm)"
2. Increase value: try 2.0, 3.0, 4.0
3. Positive values move image DOWN (away from top edge)

STEP 5: Fix Bottom Cutting
---------------------------
If image is cut on BOTTOM:
1. Find "Bottom Margin Offset (mm)"
2. Increase value: try 2.0, 3.0, 4.0
3. Positive values move image UP (away from bottom edge)

STEP 6: Add Image Padding (Optional)
-------------------------------------
For multi-image layouts (2x2, 2x3 grids):
1. Find "Image Padding (mm)"
2. Set value: 2.0-5.0
3. Adds space around each image
4. Creates professional appearance

STEP 7: Fine-Tune Position (If Needed)
---------------------------------------
For pixel-level adjustments:
1. X Position Offset: -100 to 100 pixels
   - Positive = move right
   - Negative = move left
2. Y Position Offset: -100 to 100 pixels
   - Positive = move down
   - Negative = move up
3. Use only after margin offsets don't give enough precision

STEP 8: Save Settings
----------------------
Click: "Save Layout Adjustments"
Settings apply immediately

RECOMMENDED SETTINGS TO FIX CUTTING:
-------------------------------------
Left Margin Offset: 2.0 mm
Right Margin Offset: 0.0 mm
Top Margin Offset: 0.0 mm
Bottom Margin Offset: 2.0 mm

Image Padding: 2.0 mm (for multi-image layouts)
X Position Offset: 0
Y Position Offset: 0

TESTING YOUR SETTINGS
================================================================================

STEP 1: Send Test Print Job
----------------------------
1. Send print job from X-ray console (Filmplus)
2. Wait for processing (~5-10 seconds)
3. Check output: C:\Users\abina\Desktop\print-jobs\

STEP 2: Visual Inspection
--------------------------
Open the saved JPEG/PDF and verify:
✓ Image not cut on any side
✓ Good contrast (details visible)
✓ Clean image (no excessive noise)
✓ Proper brightness (not too dark/bright)
✓ Professional appearance (padding, alignment)

STEP 3: Iterate if Needed
---------------------------
If issues remain:
- Image still cut → increase margin offsets
- Too dark → increase Exposure Correction (0.1, 0.2)
- Too noisy → increase Denoise Strength (6, 7, 8)
- Too contrasty → decrease CLAHE Clip Limit (1.5, 1.0)

================================================================================
QUICK REFERENCE - COMMON PROBLEMS
================================================================================

Problem: Image cut on LEFT side
Solution: Increase Left Margin Offset (try 2.0, 3.0, 4.0)

Problem: Image cut on BOTTOM side
Solution: Increase Bottom Margin Offset (try 2.0, 3.0, 4.0)

Problem: Image too dark
Solution: Increase Exposure Correction (try 0.1, 0.2, 0.3)

Problem: Image too bright
Solution: Decrease Exposure Correction (try -0.1, -0.2)

Problem: Image too noisy/grainy
Solution: Increase Denoise Strength (try 6, 7, 8)

Problem: Image lacks contrast (details hard to see)
Solution: Increase CLAHE Clip Limit (try 3.0, 4.0)

Problem: Image looks over-processed
Solution: Reduce CLAHE Clip Limit (try 1.5, 1.0)

Problem: Images too close together (multi-image layout)
Solution: Increase Image Padding (try 3.0, 5.0)

Problem: Enhancements making image worse
Solution: Disable one at a time to identify problematic enhancement
  - Try: Enable CLAHE: Off
  - Try: Enable Denoise: Off
  - Try: Enable Auto Exposure: Off

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Settings don't apply"
Solution:
1. Make sure you clicked "Save" button
2. Refresh the page (F5)
3. Check server log for errors
4. Verify config.json was updated

Problem: "UI controls not showing"
Solution:
1. Clear browser cache (Ctrl+Shift+Delete)
2. Hard refresh (Ctrl+F5)
3. Verify admin_ui.html is updated
4. Restart server

Problem: "Image quality worse after enhancements"
Solution:
1. Disable enhancements one by one
2. Find which enhancement causes issue
3. Adjust parameters for that enhancement
4. Or disable it entirely

Problem: "Layout adjustments not fixing cutting"
Solution:
1. Increase offset values (try 5.0, 10.0)
2. Check printer margins in Windows printer properties
3. Verify PAGE_SIZE matches actual paper size
4. Try position offsets for fine-tuning
