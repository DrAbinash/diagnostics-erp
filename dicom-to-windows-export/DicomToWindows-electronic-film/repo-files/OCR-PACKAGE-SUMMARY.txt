================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: "Tesseract not found"
Solution: Re-run setup-ocr.bat as administrator

Problem: "OCR extraction failed"
Solution: Check film has visible text, test manually with test_ocr.py

Problem: "Extracted wrong text"
Solution: Review raw OCR output, adjust parsing in server.py

Problem: "No patient info extracted"
Solution: Normal for calibration/test films without patient data

Problem: "Python libraries missing"
Solution: Run: pip install pytesseract pymupdf Pillow

Problem: "Server won't start"
Solution: Check syntax: python -m py_compile server.py

Problem: "Orthanc not receiving studies"
Solution: Check FORWARD_TO_ORTHANC=true in admin UI

Detailed troubleshooting: See OCR-INSTALLATION-GUIDE.txt Section 6

================================================================================
PERFORMANCE & ACCURACY
================================================================================

Performance:
- OCR adds ~2-3 seconds per print job
- Runs in background (doesn't block printing)
- Uses ~200 MB RAM during processing
- CPU-intensive but brief

Accuracy (tested on 10 recent films):
- Films with patient info: 50% successful extraction
- Films without patient info: 100% correct (no false positives)
- Patient name accuracy: ~90% when extracted
- Doctor name accuracy: ~85% when extracted

Limitations:
- Requires visible text on film
- Works best with high-contrast images
- May struggle with small/blurry text
- Cannot extract info that isn't printed
